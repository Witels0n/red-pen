MCQ assessments

Print, scan, and the marking is done ✓

Assessments, scans and results stay in this browser and are never uploaded. A QR code on a sheet holds only a code and the Learner ID, never a name.

  1. Build the questions and Memo, with a Topic per question.
  2. Print an answer sheet per learner, from a Class list or one master to copy.
  3. Mark: scan the sheets on a copier or take photos, then check anything uncertain.
  4. Results: a marksheet, item analysis, Topics to revise and feedback slips.
