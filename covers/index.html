Cover sheets

One scan for the class, one file per learner ✓

Names stay in this browser and are never uploaded. The QR code on a cover holds only the Learner ID, never a name.

  1. Print a Cover sheet for each learner from one of your Class lists.
  2. Staple each learner's Cover sheet to the front of their test.
  3. Scan the whole class in one batch, Cover sheets and all.
  4. Open the scan in Split a PDF and choose At cover sheets. You get one PDF per learner, named after the learner.
