# Security and privacy policy

Red Pen handles learners' work and personal information, so its central promise is that no file or
personal data ever leaves the user's browser. Anything that could break that promise is treated as a
security issue, for example:

- a page that can make a network request, load a remote resource or send data anywhere
- a way to bypass or weaken the Content Security Policy
- data being stored that the user did not choose to store, or stored where it should not be
- a malicious file (PDF, image, spreadsheet) that can run code or affect other pages

## Reporting

Please report privately through
[GitHub's private vulnerability reporting](https://github.com/Witels0n/red-pen/security/advisories/new)
rather than opening a public issue. Include steps to reproduce and, if possible, a sample file
containing no real personal information.

You can expect an acknowledgement within a week. Fixes are released by deploying to GitHub Pages;
installed copies pick up the update the next time they are opened online.

## Supported versions

Only the version currently deployed at <https://witels0n.github.io/red-pen/> is supported.
